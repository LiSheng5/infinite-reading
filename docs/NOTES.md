## 一、提示词调研（choice / chat / rp 三模式）

### 1.1 已落地结论

- **chat / rp 走纯文本**（2026-10-07 定案）：system 极简，**不再要求输出 JSON**。
  - chat：`你是一个 AI`
  - rp：`你是一个 AI，现在在这里进行角色扮演：你就是角色卡里的那个人（名字、性格、说话方式都以角色卡为准）。保持角色不出戏，也不要替玩家说话或行动。`
  - 工具说明由 `assembleAI1` 自动追加的 `[可用工具] + TOOL_POLICY_TEXT` 交代，不写进这两段。
- 连带客户端改动（已落地 `js/app.js` / `js/context.js`）：
  1. `parseAIReply` 对 chat/rp 不做 `looksJson` 判错（正文含 `{` 不再误判）；
  2. `absorbReply` 用旁白原文（截 120 字）刷新 `lastSceneSummary` 当画面参考；
  3. `planCompression` 改用 `groupByTurns`（每 4 条 messages 一幕）代替 `scene_change` 切幕；
  4. `assembleAI1` + `toPlainHistory` 回发前把 `{"narration":"…"}` 拍平——**存储格式（JSON 包装）与传输格式（纯文本）分离**。
- 代价：世界卡自报消失，改由 `update_memory` 工具 + 书记员定时校对维护。

### 1.2 二十条可执行结论（精编）

1. **位置即权重**：越靠后的指令影响越大（SillyTavern 五层模型，PHI 优先级最高）→ 最硬的格式约束放系统提示词末尾。
2. **正面指令优于禁止式**：`不要替玩家决定` → `只描写角色与环境对玩家的反应`。
3. **示例胜过解释**：给 1~2 段理想输出让模型模仿，比解释规则有效。
4. **首条回复定调**：开场白的句长 / 动作对白比 / 视角会被全程复制，开局写好收益最大。
5. **不喜欢的输出就重生成**，别顺着写（坏样本会被继续模仿）——对应本项目重试栈。
6. 官方 Immersive 四硬指标：只写一条回复 / 不代玩家行动 / 至少一段最多四段 / **高 burstiness（句长起伏）**。
7. 官方 Detailed 四关键词：缓慢推进、始终保持人设、完整感官描写、沉浸感。
8. **去 AI 味 = 去「平均化」**：自查「这句话放进任何一部小说都成立吗？成立就是平均句，重写」。
9. **改写方向是删减而非同义替换**：砍器官反应轮岗、华丽比喻、模板句式。
10. 让模型当「共同作者」，别用 roleplay / GM / NPC 这类词（会唤起游戏式语料）。
11. **选项三原则**：具体动作（「推门进去」＞「勇敢一点」）；代价点选前可见；选项间有真实差异。
12. 有代价的取舍 > 更多分支。
13. 世界要「如实回应」所选动作，不要一句通用文案收掉所有路线。
14. **NPC 要有自己的动机**：主动提问 / 行动 / 推进 = 「活人感」。
15. 不代替玩家说话 / 行动 / 决定，是中文社区「好预设」三硬标准之一（另两条：精简、格式清晰）。
16. 针对模型典型退化逐条写禁令 + 正确做法（写大纲、总结剧情、替玩家说话、搞混谁是谁）。
17. **角色卡用法**：`personality` 用可观察行为写；`mes_example` 用 `<START>` 分隔 2~3 组教口吻，但会被长上下文挤掉。
18. 开场白至少含一句角色台词、**不要以问句结尾**（否则训练出问答循环）。
19. 中文去 AI 味已有现成禁用清单（见 §1.4），可剪裁进提示词或做成书记员自查项。
20. **合规红线**：只做沉浸与文风，**不做破限 / 绕过安全策略**。

### 1.3 三模式差异对照（改提示词时用）

| | choice 剧情 | chat 对话 | rp 扮演 |
|---|---|---|---|
| 玩什么 | 故事 | 聊天 | 关系 |
| 给选项 | 是（2~3，可自由输入） | 否 | 否 |
| 长度倾向 | 2~4 句 + 钩子 | 1~3 句 | 1~3 句 + 动作白描 |
| 节奏 | 缓慢推进、留悬念 | 自然、可打岔 | 关系慢变量 |
| 记忆重点 | 伏笔、地点、时间 | 话题、偏好 | 性格、说话方式、关系阶段 |
| 首要风险 | 流水账 / 选项敷衍 | 写报告、总结 | 崩人设、抢话 |

### 1.4 中文去 AI 味规则库

**三类重灾区**：
- 器官轮岗：嘴角弧度、眼底闪过、瞳孔骤缩、喉结滚动、指节发白…
- 万能占位：「有什么东西碎了 / 堵在胸口」「某种说不清的东西」「不知为何」「一时之间」
- 模板句式：「不是 A 不是 B 而是 C」「寂静。很寂静。死一般的寂静。」「多年后他依然记得」
- 意象依赖：「像溺水的人抓住浮木」「仿佛有一只无形的手」；结构性：景物强制同步、一句超三个逗号、破折号滥用

**替代原则（比词表更重要）**：删减 > 同义替换；抽象 → 具体；一个准确细节胜过三个华丽比喻。

**可直接进提示词的简版（8 行）**：

```
【文风】
- 具体细节优先，少用形容词；一个准确的细节胜过三个比喻；
- 同一个情绪只说一遍，不反复渲染；
- 不用器官轮岗式反应（眼底/指尖/胸口/喉咙）代替情绪；
- 不用「有什么东西…」「不知为何」「一时之间」这类占位句；
- 不写「不是A而是B」「寂静。很寂静。死一般的寂静。」这类模板句式；
- 景物不为情绪当背景板：情绪变了，不要恰好起风下雨亮灯；
- 一句话尽量不超过两个逗号，不用破折号；
- 高潮可以细写，过场一句带过。
```

### 1.5 可借鉴的提示词骨架（choice）

通用底座（三模式共享）：`你是这部视觉小说的旁白，同时扮演故事世界里除玩家以外的所有角色。`——叙事要求「展现不告知、句长有起伏、缓慢推进、只描写角色与环境对玩家的反应、不替玩家说话 / 行动 / 决定」；choice 模式要求只输出一个 JSON 对象。
choice 新增：选项 2~3 个、≤12 字、用具体动作开头、代价前置；给 1 组 few-shot 示例（约 150~250 字，**放开局注入最划算，不进每轮上下文**）。

### 1.6 待讨论项（未定案）

示例放哪里（常驻 vs 仅开局注入）；系统提示词预算从 150 提到多少；choice 是否允许「无选项」回合；rp 人称策略；去 AI 味简版是否常驻；角色卡 `exampleDialogue` 注入格式。（完整 12 条见归档原稿。）

## 二、竞品调研与差异化

### 2.1 一页结论

1. **没有完全一样的对手**。赛道三层：`SillyTavern`（34.1k★，通用 LLM 前端）、`InfiPlot`（380★，云端实时全生成）、`Open Dungeon`（233★，本地一体化）。本项目站在交汇空白区：**零部署纯前端 + 用户主导的透明画师 + 可审计记忆**。
2. **最值得学**：InfiPlot（预生成 / 成本颗粒度 / 分享格式）、Open Dungeon（立绘参考图做一致性）、NeverEndingQuest（按调用点路由模型 / 编年史摘要 / 压缩缓存）。
3. **护城河不在代码**，在：一致性闭环（世界卡 ↔ 视觉卡 ↔ 图生图）做到最好、`.irstory.json` 格式生态、中文硬核文档与品牌。
4. **立刻做**：① 定许可证（✅ 已定 **MIT**，见 §3.2）；② v0.3「图生图参考」。
5. **许可警示**：SillyTavern / InfiPlot 是 AGPL-3.0，**只借鉴思路不可抄代码**；Open Dungeon / MUI Gamebook 是 MIT、AI4VisualNovel 是 Apache-2.0。

### 2.2 竞品坐标系

| 类别 | 代表 | 与本项目关系 |
|---|---|---|
| A 通用 LLM 前端 / 角色扮演 | SillyTavern(34.1k★)、RisuAI、Agnai | 生态上游（角色卡标准）+ 潜在侵蚀者 |
| B 生成式互动小说 | InfiPlot(380★)、Open Dungeon(233★)、AI4VisualNovel(87★) | 直接竞品 |
| C AI DM / 规则引擎 | NeverEndingQuest(75★) | 机制参考库 |
| D 学术与商业 | Unbounded(Google)、Hidden Door、AI Dungeon、星野 / 猫箱 | 概念来源与趋势 |

**重点竞品一句话**：
- **SillyTavern**（AGPL）：生态霸主，多后端 + 角色卡 / WorldInfo + 生图扩展 + VN Mode；生图是「扩展开关」无画师 agent。
- **InfiPlot**（AGPL）：多 agent + 边读边预生成场景，图像约 $0.00078/张；全黑盒，无自定义角色卡。
- **Open Dungeon**（MIT）：全本地，**保存立绘同时喂叙述模型与生图器**（一致性链路最值得抄的朴素版）。
- **NeverEndingQuest**（Fair Source）：叙事与规则分离 + 分层记忆（气泡记忆 / 编年史）+ **76 个调用点各自绑定模型档位**，降本 60~70%；但 284 个 issue 说明规则引擎是重资产。
- **AI4VisualNovel**（Apache-2.0）：DAG 管分支、Actor 兼写对白 + 审视觉；「它不即兴，你不预写」是可用的定位文案。

### 2.3 横向对比

| 维度 | 无限阅读 | SillyTavern | InfiPlot | Open Dungeon | NeverEndingQuest |
|---|---|---|---|---|---|
| 部署 | **双击 HTML 零依赖** | Node 20+ | Docker / 云 | Node + Ollama | Python + React |
| 画师 agent | **可对话子代理 + 工作台** | 无 | 多 agent（黑盒） | 工具调用（黑盒） | 无 |
| 记忆 | **世界卡（自报 + 校对 + 可改）+ 召回 + 压缩** | WorldInfo（手动） | 未披露 | 滚动摘要 | 最深 |
| 推进模式 | **剧情 / 对话 / 扮演 三模式** | 聊天 + VN Mode | 单一剧情 | 单一扮演 | D&D |
| 生态 | ST 卡兼容 + `.irstory.json` | 34.1k★ 生态 | `.infiplot` | 无 | 社区模块 |
| 许可 | **MIT** ✅ | AGPL ⚠️ | AGPL ⚠️ | MIT | Fair Source |

### 2.4 独特资产（别浪费）

1. **零部署**：双击即玩、无需 Key 可演示——全赛道最低获客摩擦。
2. **画师工作台**：全赛道唯一「prompt 透明 + 可改 + 可重画 + 可对话改画」。
3. **可审计记忆**：世界卡显式可视可改 + 书记员每 10 回合校准。
4. **一库三模式** + SillyTavern 卡兼容 = 蹭最大生态存量内容。
5. **离线评测 `eval/run.js`**：可升级为「长局一致性 benchmark」对外发布。
6. **文档资产**：设计稿的决议式写法在开源项目中罕见。

### 2.5 差异化路线图

**P0（v0.3 必做）**：① 图生图参考 + 角色立绘库（赛道第一痛点是画面漂移）；② **定许可证**（接收外部贡献前必做）；③ `.irstory.json` 分享闭环。
**P1（拉开身位）**：下一幕预生成；后台任务调度器（调用点成本档位）；画师风格包 `.irstyle.json`；出图后视觉自查。
**P2（加固）**：PWA 化；TTS 多声线；人物关系图；视频生成适配器；导入静态体检；公版世界开局包。

**一句话定位（建议写进 README 首屏）**：

> 别人让你「聊」故事（SillyTavern）、让 AI「演」给你看（InfiPlot）；无限阅读让你和 AI 一起演，而且画师就在你手边——每一张画的 prompt 你都能看见、能改、能商量。

### 2.6 护城河与风险

- 护城河分层：体验层（一致性闭环）★★★ / 格式层（`.irstory.json` 等）★★★ / 内容层 ★★ / 品牌层 ★★ / 技术层 ★★（易抄，当获客漏斗）。
- 风险：① **许可红线**（AGPL / Fair Source 只借鉴）；② ST 扩展生态与 InfiPlot roadmap 可能夹击，需快速迭代；③ ~~localStorage 容量硬伤~~（**已迁 IndexedDB，v0.3.0**）；④ 浏览器直连 CORS + Key 明文需在文档明示；⑤ 内容边界（参考 Open Dungeon 争议）。

### 3.2 开源基座（第一步）

**许可证决策**：传播优先 → **MIT**（最省事）或 **Apache-2.0**；想防白嫖托管 → AGPL-3.0；双许可 = 开放核心 + 商业托管。
**第三方资源许可**：霞鹜文楷 OFL-1.1；Google Fonts 各款逐字体确认——打包需随包分发字体与许可，写进 `THIRD-PARTY-NOTICES.md`。
**最小仓库骨架**：`LICENSE`、`README.md`（补徽章 / Demo / 截图）、`README.en.md`、`CONTRIBUTING.md`、`CODE_OF_CONDUCT.md`、`SECURITY.md`、`CHANGELOG.md`、`THIRD-PARTY-NOTICES.md`、`ARCHITECTURE.md`、`.gitignore`、`.github/`（ISSUE / PR 模板 + `ci.yml` + `release.yml`）、`docs/`。
`.gitignore`：`node_modules/`、`*.log`、`dist/`、`.codebuddy/`、`.vscode/`。
**版本号统一**：`VERSION` 文件（当前 `0.3.0`），`?v=` 由 `tools/sync-version.mjs` 注入到 `index.html` / `package.json`，打 tag `v0.3.0`。

### 3.3 降低门槛：五级路径

| 级别 | 方案 | 工作量 | 解决什么 |
|---|---|---|---|
| **L0** | 在线 Demo（GitHub / Cloudflare Pages） | 半天 | **零安装**，可搜索、可分享 |
| L1 | 单文件 HTML（`ir.html`） | 1 天 | 摆脱「一堆文件」，可附件发送 |
| L2 | PWA（manifest + SW） | 1 天 | 桌面图标、离线打开 |
| L3 | 便携包 + 一键启动 `启动.bat` | 半天 | 绕开 `file://` 差异，起本地服务 |
| L4 | 桌面 App（**Tauri 2**，非 Electron） | 3~5 天 | 真软件体验、可存 Key 到系统凭据 |
| L5 | Docker / NAS 镜像 | 1 小时 | 自托管、内网访问 |

**优先级：只做一件事 → 做 L0 + `?demo=1`**（启动时读参数自动进离线演示，砍掉「下载 / 安装 / 配 Key」三道门槛）。

**关键要点**：
- L1 单文件：写 `tools/bundle-single-file.mjs` 内联 CSS / JS；坑：转义 `</script>`、内联后 `?v=` 失效、`file://` origin 与多文件版存储不互通（提示导出导入迁移）。
- L2 PWA：`manifest.webmanifest` + `sw.js`（cache-first 静态资源，**API 域名一律不缓存**）；`file://` 下 SW 不可用，必须 https / L0 部署。
- L4 Tauri 2：体积 3~10MB（Electron 80~150MB+），零前端改造；**坑**：`connect-src` 必须放通 `https:`/`http:` 否则 API 全被 CSP 拦；桌面版 origin `tauri://localhost` 与网页版存储隔离。
- 体验优化：**字体本地化**（`fonttools pyftsubset` 子集化，国内首屏秒开）、首次运行默认离线演示、免费模型一键体验、错误人话化。

### 3.4 生态四飞轮

> 生态 ≠ 插件框架；对纯前端项目，**「普通人能贡献内容」比「程序员能写插件」重要十倍**。

1. **贡献者飞轮**：`CONTRIBUTING.md` 首句写「无需 npm install、改 `js/*.js` 刷新即生效」；backlog 拆 issue + 标签；`eval/run.js` 进 CI（不花 API，防记忆机制被改坏）；`ARCHITECTURE.md` 给数据流地图。
2. **扩展点飞轮**（轻量钩子 > 插件框架）：Provider 注册表；主题 = CSS 变量 + 主题文件（纸白主题打头）；预留 2~3 个渲染钩子（如 `IR.hooks.onSceneRendered`）。
3. **内容飞轮（核心）**：`.irstory.json`（完整故事）/ `.irstyle.json`（视觉风格包）/ 角色卡（兼容 ST V2/V3）/ 开局包（可含公版 IP）；开纯内容仓库 `infinite-reading-packs` + 格式 JSON Schema + 静态精选画廊 + 应用内「从 URL 导入」。
4. **品牌飞轮**：中文首发（linux.do、V2EX、少数派、B 站、小红书）；英文（r/SillyTavernAI、r/LocalLLaMA、Show HN、Product Hunt）；每次 Release 配 15~30 秒录屏；README 首屏放会动的 GIF。

### 3.6 坑与红线

1. Google Fonts 国内不通 → 字体必须本地化。
2. 本地存储（IndexedDB）三处不一致（网页版 / 单文件 `file://` / 桌面 `tauri://`）→ 每版都要显眼提供导出导入迁移。
3. **Key 安全**：现 Key 明文存 IndexedDB；桌面版用系统凭据库，网页版至少 README 明示 + 支持「不保存」。
4. **不要把打包当生态**：安装包解决「进门」，生态靠内容格式 + 贡献体验。
5. 不要为打包破坏「零构建」：`tools/` 脚本全部可选，`package.json` 只作开发工具。
6. 许可证一致性：定了 MIT 后续收紧只对新代码生效；第三方资源许可随包分发。
7. macOS 未签名会被 Gatekeeper 拦、Windows SmartScreen 会拦 → README 写绕行或买证书。
8. CORS 无解部分如实告知 → 保留本地服务 / Docker / 桌面版三条兜底。
