本地存储与备份

两种备份：.irbackup.json（全部故事 + 模型设置 + 用户画像，不含原图，体积可控）与 .zip（同一份正文 + 全部原图，换设备时连图一起搬）。把文件拖回书架窗口即可整体还原（同 id 的故事会被覆盖，其它故事保留）。只想带走单个故事时，用书架卡片上的「导出 → 附带原图」。

数据存在哪？什么情况下会丢？

全部数据只存在这台设备的这个浏览器里（主库是 IndexedDB，容量由浏览器按磁盘空间分配，通常远大于 localStorage 的约 5MB；原图以 Blob 单独存放），没有任何服务器。下列操作会让它消失，注意避开：

· 清「Cookie 和网站数据 / 站点数据」——会全删（只清「缓存 / 缓存的图片和文件」不受影响）
· 无痕 / 隐私模式——关窗即没
· 换浏览器、换设备、换打开方式（file:// 和 http://localhost 是两套独立数据，互不相通）
· Safari（含 iOS）：7 天没和这个页面交互，ITP 会自动清除脚本可写存储 → 建议「添加到主屏幕」或常来点一下
· 磁盘空间紧张时，浏览器可能自动淘汰
