# 本地服务（sidecar）

这是「无限阅读」的**可选**本地伴侣进程。它提供三个默认关闭的功能：

| 功能 | 说明 |
|---|---|
| 邮件 | 代你写信 / 存草稿 / 发信（收件人白名单硬校验、每日上限、审计）；收件箱接口预留，本期**不支持读信** |
| 模型主动行动 | 定时写信、定时发消息（一次性 / 固定间隔 / cron 含时区），触发器持久保存 |
| 购物支付 | 受限代下单（额度、白名单、冷静期、人工确认），**AI 永远拿不到支付凭证** |

> 不启动它，应用照常使用：这三个功能在界面上显示「需要启动本地服务」并保持禁用，其余功能完全不受影响。

## 为什么需要它

前端是纯静态页面，浏览器里做不到三件事：**发邮件**（本期经 Resend 的 HTTP API 只发不收）、**关掉页面后仍然按点触发**、**把支付策略放在模型改不到的地方强制执行**。所以这些能力放在这个只跑在本机的进程里。

## 启动

```bash
node sidecar/server.mjs          # 第一次启动会打印 token
node sidecar/server.mjs --show-token   # 再次查看 token
```

启动后：

1. 终端里会打印 `token`，把它复制到应用「设置 → 本地服务 → token」；
2. 服务只绑 `127.0.0.1:4319`（回环地址），**局域网 / 外网都访问不到**；
3. 前端会探测 `http://127.0.0.1:4319/health`，探测通过后三个功能的开关才会亮起。

> Windows 旧版 `cmd.exe` 若把中文显示成乱码，先执行一次 `chcp 65001` 切到 UTF-8；Windows Terminal / PowerShell 7 通常无需处理。

## 单进程约定

本项目按**单进程**设计：重复启动会被拒绝（锁文件 `sidecar/data/.lock` + 端口占用双重检测），这样定时触发不会被跑两遍。请勿同时启动多个实例。

## 配置与安全

- 白名单、额度、每日上限、免打扰时段、token **只存在** `sidecar/data/config.json`，是这些安全项的唯一真源；前端设置页只是它的编辑界面。
- 配置文件 `config.json` 权限为 `600`（POSIX）；Windows 上 `mode:0o600` 无效，写盘时会用 `icacls` 尽力收紧为仅当前用户可读写。`sidecar/data/` 已加入 `.gitignore`，不会进版本库。
- 除 `/health` 外所有接口都需要 `Authorization: Bearer <token>`；目的是防本机其它程序或网页乱调你的服务。SSE（`/api/events`）例外：`EventSource` 带不了请求头，token 也不进 URL，改为先 `POST /api/events/ticket` 用 Bearer 换一张 30 秒有效的一次性 ticket 再连接。
- 邮件密钥（如 Resend API Key）只存本地配置文件；服务不代管任何人的钱或邮箱。

## 风险提示

- **AI 可能出错，请设置合理额度。** 默认额度为 0、白名单为空 = 什么都不放行，必须由你手动开启。
- 支付策略在**代码层**强制执行，但它是**防误操作与可审计**，不是"防你自己"——你拥有本机文件，理论上可以改配置或代码绕过。
- 本服务**不接真实支付回调**，本期只有「模拟支付」与「仅生成订单、由你在微信 / 支付宝里手动付款」两种模式；不会自动操控任何支付 App，也不会保存支付密码。
- Node 版本要求：见项目根 `package.json` 的 `engines`。`node:sqlite` 需要 Node ≥ 22.5；22.5–23.3 需加 `--experimental-sqlite`，≥ 23.4 无需。
